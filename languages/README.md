# Translations

This directory contains the translation files for the Business Hours Block plugin.

## Generating the .mo file

The `.mo` file is the compiled binary that WordPress uses at runtime. Generate it from the `.po` file using the `msgfmt` command:

```bash
cd languages/
msgfmt telex-hours-block-de_DE.po -o telex-hours-block-de_DE.mo
```

## Generating the JavaScript translation file

For editor (block) translations, WordPress needs a Jed-format JSON file. Generate it using WP-CLI:

```bash
wp i18n make-json languages/telex-hours-block-de_DE.po languages/ --no-purge
```

This creates JSON files like `telex-hours-block-de_DE-<hash>.json` that WordPress automatically loads for the block's JavaScript.

## Generating a fresh .pot file

To regenerate the POT template from source:

```bash
wp i18n make-pot . languages/telex-hours-block.pot --domain=telex-hours-block
```

## Loading translations

The plugin uses the `telex-hours-block` text domain. WordPress automatically loads translation files from the `languages/` directory when the plugin is activated and the site language is set to `de_DE`.

For JavaScript translations to load in the block editor, WordPress needs the JSON files generated by `wp i18n make-json`. The block's `editorScript` handle is used to match the correct JSON file.
